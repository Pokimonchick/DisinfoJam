# Комната тамагочи

`Scripts/tamagotchi_room.gd` (`TamagotchiRoom`) — только визуальный слой комнаты. Родитель размещает его в макете 1920×1080 и отвечает за масштабирование, интерактивные зоны и состояние игры.

## API

```gdscript
var room := TamagotchiRoom.new()
canvas.add_child(room)
room.show_heroine = true
room.sleeping = false
room.set_playback_paused(false)
room.play_fish_feedback()
```

- `show_heroine` показывает отдельную дневную героиню и её тень; ночной ролик уже содержит спящую героиню.
- `sleeping` переключает дневной и ночной ролики. Ночью отдельные героиня, тень, кровать и полка скрыты, поскольку они уже есть в готовом видео.
- `set_playback_paused(value)` останавливает видео, смену поз героини и отклик рыбок. Вызывать при общей паузе и открытии настроек, затем передавать актуальное состояние при закрытии.
- `play_fish_feedback()` показывает на 1,8 секунды пузырь «Буль!» возле аквариума. Игровые показатели не меняет.

Скрытие компонента или его родителя приостанавливает видео и `_process`. После показа воспроизведение продолжается, если общая пауза снята. Используется один `VideoStreamPlayer`, поэтому дневной и ночной ролики одновременно не декодируются. Все визуальные узлы пропускают мышь.

## Источники и слои

Исходные файлы сохранены без изменений. Корень изображений: `Assets/Assets for new version of game/tamagochi/`.

Дневной порядок от заднего к переднему:

1. `Assets/Generated/Tamagotchi/day_room.ogv`: 48 JPEG кадров комнаты, блик и 19 кадров кошки на телевизоре. Короткая последовательность кошки повторяется.
2. Тень `IMG_1952.PNG` — `IMG_1955.PNG`.
3. Героиня `IMG_1944.PNG` — `IMG_1947.PNG`, 6 кадров/с, позиция `(620, 280)`, размер `(462, 745)`. Альфа-силуэт ног заканчивается около `y=1003` на ковре.
4. `Тамагочи/Кровать пнг/Comp 1/Кровать_00000.png`.
5. `Тамагочи/Кровать пнг/Comp 1/Полка_00000.png`.

В исходном блике белая диагональная полоса находится в прямоугольнике `(1104,231,232,295)`, который на JPEG-фоне пересекает окно. При подготовке видео этот фрагмент помещён в экран телевизора `(1238,458,136,90)` с альфой 0,22. Кошка остаётся в исходных координатах: её лапы на `y=436` совпадают с верхом телевизора.

Ночь: `Assets/Generated/Tamagotchi/night_room.ogv`, получен из предоставленного `ГОСПОДИ ПОМОГИ.mp4`. Это готовая композиция комнаты со спящей героиней, без отдельного наложения дневных слоёв. Оба ролика — Theora, 1920×1080, 24 кадра/с, около 2 секунд, без аудио.

Размеры подготовленных файлов: дневной — **954 067 байт**, ночной — **965 659 байт**. Декодированные RGBA-текстуры восьми небольших кадров героини/тени и двух полноэкранных передних слоёв занимают около **26,3 МиБ** без учёта импорта, копий CPU/GPU и буферов видеодекодера. Полноэкранные анимационные PNG-последовательности в игре не загружаются; только их RGBA-кадры потребовали бы более 0,8 ГиБ.

## Повторная подготовка видео

Нужен FFmpeg с `libtheora`. Выполнять из корня проекта. Это подготовка медиа; приложение или Godot для неё не запускаются. В Python используется список аргументов, чтобы сохранить кириллицу и пробелы в путях.

```python
from pathlib import Path
import subprocess

ffmpeg = "ffmpeg"  # Или полный путь к исполняемому файлу.
room = Path("Assets/Assets for new version of game/tamagochi/Тамагочи")
output = Path("Assets/Generated/Tamagotchi")
output.mkdir(parents=True, exist_ok=True)
filters = (
    "[1:v]crop=232:295:1104:231,scale=136:90:flags=neighbor,"
    "colorchannelmixer=aa=0.22[glint];"
    "[0:v][glint]overlay=1238:458:format=auto[lit];"
    "[lit][2:v]overlay=0:0:format=auto,format=yuv420p[out]"
)
subprocess.run([
    ffmpeg, "-y", "-framerate", "24", "-i",
    str(room / "Тамагочи фон анимация/Comp 1/Фон анимация день_%05d.jpg"),
    "-framerate", "24", "-i",
    str(room / "Блик анимация/Comp 1/Блик_%05d.png"),
    "-loop", "1", "-framerate", "24", "-i",
    str(room / "Тамагочи кошка анимация/Comp 1/Кошка анимация_%05d.png"),
    "-filter_complex", filters, "-map", "[out]", "-frames:v", "48",
    "-an", "-c:v", "libtheora", "-q:v", "8", str(output / "day_room.ogv"),
], check=True)
night_source = Path.home() / "Downloads/Telegram Desktop/ГОСПОДИ ПОМОГИ.mp4"
subprocess.run([
    ffmpeg, "-y", "-i", str(night_source), "-an", "-c:v", "libtheora",
    "-q:v", "8", "-pix_fmt", "yuv420p", str(output / "night_room.ogv"),
], check=True)
```

Служебные файлы импорта созданы штатным импортом редактора Godot; вручную они не редактировались. После первого прохода, подготовившего новые шрифты и курсор для автозагрузки, заключительный импорт завершился без ошибок в журнале. Игровые тесты и запуск игры не выполнялись по запросу пользователя; совмещение в игровом окне остаётся непроверенным.
