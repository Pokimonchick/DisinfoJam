# Комната тамагочи

`Scripts/tamagotchi_room.gd` (`TamagotchiRoom`) — только визуальный слой комнаты. Родитель размещает его в макете 1920×1080 и отвечает за масштабирование, интерактивные зоны и состояние игры.

## API

```gdscript
var room := TamagotchiRoom.new()
canvas.add_child(room)
room.show_heroine = true
room.sleeping = false
room.set_playback_paused(false)
room.play_fish_feedback()
```

- `show_heroine` показывает отдельную дневную героиню и её тень; ночной ролик уже содержит спящую героиню.
- `sleeping` переключает дневной и ночной ролики. Ночью отдельные героиня, тень, кровать и полка скрыты, поскольку они уже есть в готовом видео.
- `set_playback_paused(value)` останавливает видео, смену поз героини, блик окна и отклик рыбок. Вызывать при общей паузе и открытии настроек, затем передавать актуальное состояние при закрытии.
- `play_fish_feedback()` показывает на 1,8 секунды пузырь «Буль!» возле аквариума. Игровые показатели не меняет.

Скрытие компонента или его родителя приостанавливает видео и `_process`, а текущий блик прекращается. После показа видео продолжается, если общая пауза снята. Используется один `VideoStreamPlayer`, поэтому дневной и ночной ролики одновременно не декодируются. Визуальные слои пропускают мышь; отдельная область окна получает наведение.

## Источники и слои

Исходные файлы сохранены без изменений. Корень изображений: `Assets/Assets for new version of game/tamagochi/`.

Дневной порядок от заднего к переднему:

1. `Assets/Generated/Tamagotchi/day_room.ogv`: 48 JPEG кадров комнаты и 19 кадров кошки на телевизоре. Блик в видео не запечён. Короткая последовательность кошки повторяется.
2. Тень `IMG_1952.PNG` — `IMG_1955.PNG`, позиция `(629, 383.3)`, размер `(438.9, 707.75)`, альфа 0,5. Смещение относительно контейнера героини — 74 исходных пикселя вниз с учётом общего масштаба. Овал находится под ступнями.
3. Героиня `IMG_1944.PNG` — `IMG_1947.PNG`, 6 кадров/с, масштаб исходного PNG 0,95, позиция `(629, 313)`, размер `(438.9, 707.75)`. Видимый силуэт примерно `(658.45, 372.85)…(982.4, 999.85)`, по предоставленному макету комнаты.
4. `Тамагочи/Кровать пнг/Comp 1/Кровать_00000.png`.
5. `Тамагочи/Кровать пнг/Comp 1/Полка_00000.png`.

Блик окна хранится отдельно в `Assets/Generated/Tamagotchi/window_glint.png`: 48 кадров по 232×308, 8 столбцов, атлас 1856×1848. Во всех исходных PNG видимые пиксели помещаются в прямоугольник `(1104, 218)…(1336, 526)`; эта общая область обрезана без изменения масштаба, а сам атлас стоит в комнате в `(1104, 218)`. Исходные кадры сохранены без изменений.

Наведение на окно `(754, 124, 584, 550)` запускает одну последовательность 24 кадра/с (2 секунды). Удержание курсора не повторяет блик; после выхода и нового наведения он проигрывается снова. Пауза замораживает кадр, скрытие комнаты и ночь прекращают анимацию. Кадры источника белые с альфой; умножение белого не меняло бы фон, поэтому `Shaders/tamagotchi_window_glint.gdshader` использует режим **Overlay** с альфой 0,22 вместо обычного белого наложения.

`Shaders/tamagotchi_room_grade.gdshader` слегка усиливает контраст (1,10) и насыщенность (1,08) дневного видео и отдельных слоёв, приближая комнату к референсу. Ночной ролик и интерфейс не проходят через этот шейдер. Кошка остаётся в исходных координатах: её лапы на `y=436` совпадают с верхом телевизора.

Ночь: `Assets/Generated/Tamagotchi/night_room.ogv`, получен из предоставленного `ГОСПОДИ ПОМОГИ.mp4`. Это готовая композиция комнаты со спящей героиней, без отдельного наложения дневных слоёв. Оба ролика — Theora, 1920×1080, 24 кадра/с, около 2 секунд, без аудио.

Размеры подготовленных файлов: дневной — **943 802 байта**, ночной — **965 659 байт**. Декодированные RGBA-текстуры восьми небольших кадров героини/тени и двух полноэкранных передних слоёв занимают около **26,3 МиБ** без учёта импорта, копий CPU/GPU и буферов видеодекодера. Атлас блика занимает 112 751 байт в PNG и около 13,1 МиБ в декодированном RGBA. Полноэкранные анимационные PNG-последовательности в игре не загружаются; только их RGBA-кадры потребовали бы более 0,8 ГиБ.

## Повторная подготовка видео

Нужен FFmpeg с `libtheora`. Выполнять из корня проекта. Это подготовка медиа; приложение или Godot для неё не запускаются. В Python используется список аргументов, чтобы сохранить кириллицу и пробелы в путях.

```python
from pathlib import Path
import subprocess

ffmpeg = "ffmpeg"  # Или полный путь к исполняемому файлу.
room = Path("Assets/Assets for new version of game/tamagochi/Тамагочи")
output = Path("Assets/Generated/Tamagotchi")
output.mkdir(parents=True, exist_ok=True)
filters = "[0:v][1:v]overlay=0:0:format=auto,format=yuv420p[out]"
subprocess.run([
    ffmpeg, "-y", "-framerate", "24", "-i",
    str(room / "Тамагочи фон анимация/Comp 1/Фон анимация день_%05d.jpg"),
    "-stream_loop", "-1", "-framerate", "24", "-i",
    str(room / "Тамагочи кошка анимация/Comp 1/Кошка анимация_%05d.png"),
    "-filter_complex", filters, "-map", "[out]", "-frames:v", "48",
    "-an", "-c:v", "libtheora", "-q:v", "8", str(output / "day_room.ogv"),
], check=True)
# Подготовка компактного атласа без изменения исходных PNG.
from PIL import Image
atlas = Image.new("RGBA", (232 * 8, 308 * 6))
for index, source in enumerate(sorted((room / "Блик анимация/Comp 1").glob("*.png"))):
    frame = Image.open(source).convert("RGBA").crop((1104, 218, 1336, 526))
    atlas.paste(frame, ((index % 8) * 232, (index // 8) * 308))
atlas.save(output / "window_glint.png", optimize=True)

night_source = Path.home() / "Downloads/Telegram Desktop/ГОСПОДИ ПОМОГИ.mp4"
subprocess.run([
    ffmpeg, "-y", "-i", str(night_source), "-an", "-c:v", "libtheora",
    "-q:v", "8", "-pix_fmt", "yuv420p", str(output / "night_room.ogv"),
], check=True)
```

Служебные файлы импорта создаются штатным импортом редактора Godot; вручную они не редактируются.
